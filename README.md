# 匿名作品集 · Anonymous Portfolio

一份**不含任何身份信息**的作品集 UI 展示：没有姓名、学校、城市、联系方式，也没有指向任何外部身份的链接。纯 UI 展示用。

与主站（完整版）样式完全一致，差异只在内容数据（`js/data.js`、`js/i18n.js`、`index.html` 的文案与链接）。

## 本地预览

```bash
python -m http.server 8080
```

## 改内容

- 动态内容（技能/项目/统计/AI 问答）：`js/data.js`
- 静态文案（中英对照）：`js/i18n.js`
- 项目链接：`js/data.js` 里 `links` 填入 `href` 即会显示「在线访问」按钮（填了就会暴露身份，想清楚再填）

## 功能与主站一致

中英双语 · Web Audio 生成式背景音乐 · 深/浅主题 · 键盘 0-5 跳转 · 星座连线 Canvas · 自定义光标 · 磁吸按钮 · AI 问答（离线关键词版）
